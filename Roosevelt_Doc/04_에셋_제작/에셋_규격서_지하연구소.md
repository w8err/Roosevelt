# 에셋 규격서: 지하 연구소 모듈

작성 2026-09-12. 모든 실내 모듈 에셋(벽, 바닥, 천장, 바리에이션)은 이 문서를 따른다. 스타일 레퍼런스는 `../03_아트_레퍼런스/그래픽_레퍼런스.md`.

## 1. 크기와 격자
| 항목 | 값 |
|---|---|
| 격자 | 1m (세부 배치는 0.5m) |
| 벽 | 폭 2m × 높이 3.5m × 두께 0.2m |
| 바닥 | 2 × 2m, 두께 0.1m, 윗면이 z=0 |
| 천장 | 2 × 2m, 두께 0.1m, 아랫면이 z=3.5 |
| 단위 | Blender 1 unit = 1m = Unity 1 unit |

## 2. 기준점과 방향
- 벽: 원점은 앞면 왼쪽 아래 모서리. 앞면이 -Y를 보고, 두께는 +Y 방향(0~0.2)
- 바닥: 원점은 모서리. x 0~2, y 0~2
- 천장: 원점은 모서리. 아랫면(방 쪽)이 -Z를 봄
- 회전은 90도 단위로만 조립한다

## 4. 색
- 팔레트 5색만 쓰고 명암만 파생한다: #5b9a8c #a6d8af #f4e1a4 #f8b89b #d64c4c

## 5. 형태
- 실루엣으로 읽혀야 한다. 걸레받이, 안전선 몰딩, 문틀 같은 구조는 몸체 밖으로 2cm 이상 돌출
- 디테일(타일, 얼룩, 금)은 텍스처로 처리한다
- 폴리곤 예산(삼각형): 벽 60 이하, 바리에이션 150 이하, 바닥 20 이하, 천장 40 이하(조명 포함 시 100 이하)
- 셰이딩은 flat. PS1식 정점 흔들림, 텍스처 왜곡은 모델이 아니라 셰이더에서 처리

## 6. 이름
`SM_Lab_<종류>_<변형>_<폭x높이cm>`
- 예: `SM_Lab_Wall_Plain_200x350`, `SM_Lab_Wall_Door_200x350`, `SM_Lab_Floor_Drain_200x200`
- 텍스처는 `T_`, 머티리얼은 `M_` 접두사

## 7. 바리에이션 목록 (1차)
- 벽: Plain(깔끔), Dirty(흘러내린 자국·타일 때), Door(문틀, 개구부 1.0×2.1m), CornerIn / CornerInDirty, Window(관찰창), Damaged(파손), CornerOut
  - CornerIn: 몰딩 왼쪽 끝(로컬 x=0)을 2cm 잘라낸 벽. 벽 왼쪽 끝이 안쪽 모서리에 닿는 자리에 둔다. 일반 벽끼리 만나면 몰딩이 2×2cm 겹쳐 깜빡인다
- 바닥: Plain(깔끔), Stained(얼룩), Drain(배수구)
- 천장: Plain(조명 없음), Light(1×1m 조명 기구), Vent(환풍구)
- 제작 완료(2026-09-12): 벽 Plain·Dirty·Door·DoorPair·CornerIn·CornerInDirty, 바닥 Plain·Stained, 천장 Plain·Light
  - DoorPair: 등을 맞댄 두 벽으로 방을 이을 때 Door 벽의 반대편에 쓰는 문 벽. 문틀 뒤쪽이 3cm 짧아(y 0.17) 두 문틀이 겹치지 않고 맞닿는다. 문짝은 Door 쪽에만 단다

## 10. 실내 프랍 공통 규격
연구실·사무실·복도에 배치하는 독립 프랍은 이 절을 따른다. 건축 모듈의 규격을 바꾸거나 벽·바닥 아틀라스 영역을 공유하지 않는다.

| 항목 | 값 |
|---|---|
| 배치 격자 | 기본 0.5m, 작은 소품은 0.25m |
| 원점 | 바닥에 닿는 면의 중앙. 벽걸이 프랍은 벽에 닿는 면의 중앙 |
| 기본 방향 | 프랍의 정면은 -Y. 좌우 대칭이 아닌 프랍도 이 방향으로 제작 |
| 크기 단위 | cm 표기는 실제 크기. Blender 1 unit = Unity 1 unit = 1m |
| 회전 | 기본 배치는 90도 단위. 어수선함 연출용 소품만 Z축 ±5° 이내 허용 |
| 텍셀 밀도 | 본체 64px/m, 손에 드는 소품·라벨은 128px/m |
| 셰이딩 | Flat. 둥근 손잡이·바퀴도 가능한 한 6~8면으로 단순화 |
| 재질 | 원칙적으로 `M_Lab_Props_Atlas` 하나. 발광 화면·램프만 `M_Lab_Props_Emissive` 추가 허용 |

### 10.1 프랍 텍스처와 색
- 프랍 전용 아틀라스: `T_Lab_Props_Atlas` 512×512. 1차 프랍 전체가 공유한다. 텍스처 임포트 설정은 3절과 동일하다.
- 화면·경고등의 발광 마스크는 `T_Lab_Props_Emissive` 256×256에 모은다. 밝기는 셰이더에서 조절하며, 별도 라이트를 프랍마다 붙이지 않는다.
- 4절의 5색 팔레트를 우선 사용한다. 금속·검은 플라스틱은 #5b9a8c를 어둡고 채도 낮게 파생하고, 종이·라벨은 #f4e1a4를 기준으로 한다.
- 정보가 있는 표면(모니터 화면, 문서, 라벨)은 실제 읽을거리보다 큰 도형·짧은 기호로 읽힌다. 화면에 장문 텍스트를 굽지 않는다.
- `T_Lab_Props_Atlas` 영역 (px, 왼쪽 아래 기준. 2026-09-13 1차 가구에서 사용, `Art/tools/make_lab_props.py`)

| 판재 | x 160~384, y 0~224 | 책상 상판, 접수대 몸체·상판, 서랍 앞면 |

### 10.2 형태와 충돌
- 멀리서 식별되는 기능 실루엣을 우선한다. 책상은 상판과 서랍, 캐비닛은 손잡이와 파일 칸, 장비는 렌즈·암·화면을 최소 2cm 이상 돌출해 구분한다.
- 전선, 종이 더미, 얼룩, 나사 같은 미세 요소는 텍스처 또는 1~3개의 저폴리 부속 메쉬로 처리한다. 프랍 하나에 실제 가는 케이블을 많이 만들지 않는다.
- 플레이어가 닿는 본체에는 단순 BoxCollider를 사용한다. 의자 바퀴·손잡이·모니터 받침 등 돌출부에 개별 충돌체를 붙이지 않는다.
- 열리거나 움직이는 요소는 본체와 분리한 프리팹으로 제작한다. 정적 배경 프랍은 하나의 FBX로 합친다.

### 10.3 이름과 출력
- 메시: `SM_LabProp_<종류>_<변형>_<가로x세로x높이cm>`
- 프리팹: `PF_LabProp_<종류>_<변형>`
- 예: `SM_LabProp_Desk_Metal_160x70x75`, `SM_LabProp_Terminal_CRT_45x45x40`, `PF_LabProp_Cabinet_Filing`.
- 위치: FBX는 `Roosevelt/Assets/Art/Environment/Lab/Props/Meshes/`, 텍스처는 `Textures/`, 프리팹은 `Roosevelt/Assets/Prefabs/Environment/Lab/Props/`.

## 12. 프랍 조합 규칙과 검수
- **연구 책상 세트**: `Desk_Metal` + `Terminal_CRT` + `Keyboard_Compact` + `Chair_Rolling`을 기본 조합으로 쓴다. 화면 방향은 벽 또는 플레이 동선 반대편을 향하게 둔다.
- **기록 사무실 세트**: 책상 1~2개, 파일 캐비닛 1~3개, 게시판 1개, 휴지통 1개. 캐비닛은 출입문 앞 0.8m와 탈출 동선을 막지 않는다.
- **실험대 세트**: 책상 또는 카트 위에 현미경·시료 보관함을 1~2개만 올린다. 모든 표면을 소품으로 꽉 채우지 않아 상호작용 물체와 구분한다.
- **창고 세트**: 선반 1개당 상자 적재 변형은 최대 1개. 같은 상자 회전을 반복하지 말고, 빈 선반을 최소 한 칸 남긴다.
- 검수 시 320×240 목표 렌더에서 3m·8m 거리의 식별성을 확인한다. 각 프랍은 이 거리에서 종류가 구별되어야 한다.
- 한 방의 실시간 광원, 프랍 수, 드로우콜은 씬 예산 문서가 생기기 전까지 임시로 제한하지 않는다. 다만 발광 프랍과 그림자 투사 프랍은 씬 단위로 수를 기록한다.
