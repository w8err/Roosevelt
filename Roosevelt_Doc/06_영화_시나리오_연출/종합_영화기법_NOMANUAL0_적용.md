## 1. 세 문서가 합의한 것

1. **결말은 먼저 암시한다.** 서스펜스가 서프라이즈보다 강하다(히치콕). 오이디푸스·선셋 대로·느와르 보이스오버의 계보와 앞 분석의 Mouthwashing 결론이 같은 방향이다
2. **하루 = 시퀀스 하나.** 3막·15비트는 참고만. 0일차 = 기, 5일차 = 진실을 아는 순간이 곧 갇히는 순간(아나그노리시스와 페리페테이아가 동시에)
3. **꿈은 린치보다 타르콥스키.** 비논리적 편집보다 끊기지 않고 느리게 흐르는 시간. 나무까지 걸어가는 구간이 이미 그 선택이다
4. **드물게 쓸수록 강하다.** 시선 고정, 정지 카메라, 점프 컷, 글리치 전환은 날짜 경계와 5일차에만
5. **루즈벨트는 마이클 콜레오네형.** 지키려던 동기가 파괴로 뒤집힌다. 0편에서는 "필요한 희생"을 듣기만 하고, 1편에서 직접 쓰는 순간 인물 변화가 완성된다

## 2. 어긋난 것과 정리

| 쟁점 | 문서 | 정리 |
|---|---|---|
| **"연출 컷", 180도 규칙, 숏-리버스숏으로 대화 연출** | 연출 기법 1.4·3.1 | 지금 대화는 컷이 없는 1인칭이다(`DialogueView` + `CharacterFacing`). 컷 기반 문법은 그대로 못 쓴다. 번역 문서 2장대로 **거리와 NPC의 몸 방향**으로 옮긴다. 180도 규칙을 "5일차에 한 번 깨기"는 공간 배치(같은 NPC가 반대편에 서 있음)로 대신할 수 있다 |
| **문=짧은 암전, 수면·기상=긴 암전** | 연출 기법 3장 | **이미 구현돼 있다.** `TransitionSettings`: 문 0.35/0.15/0.35초, 수면 1.75/1.25/1.75초, 기상 1.75초 + "Day N" 캡션 2초 |
| **착석 콘티 "새 시스템 없이 파라미터만"** | 연출 기법 7장 | 두 곳은 코드 추가가 필요하다. ① `PlayerCameraFeel`에 흔들림을 끄는 입구가 없다(착석 중에도 숨쉬기 흔들림 유지가 현재 동작). ② `Ambience`는 전역 볼륨 하나라서 "환경음은 줄이고 저주파 드론만 남기기"가 안 된다. 드론을 `Ambience`와 별도로 재생하거나 채널을 나눠야 한다 |
| 콘티 S2 "흔들림 0" vs S4 "숨쉬기는 유지" vs S5 "완전 고정" | 연출 기법 7장 | 한 줄로 정리: S2에서 **걷기 흔들림만** 0으로, 숨쉬기는 S5 홀드 중간에 멈춤. 숨이 멎는 순간 자체를 신호로 씀 [제안] |
| 여자·아이 실루엣이 날마다 선명해지고 5일차에 얼굴이 드러날 수도 있음 | 비트시트 2일차 | 기획 4장은 "얼굴·정체 불명확, 두루뭉술하게". 드러낼지는 **사용자 결정**. 권장: 끝까지 안 드러내고, 대신 루즈벨트만 알아보는 소품(옷·머리끈 등)으로 알게 함 |
| 1일차에 "혈통·고문서" 단어 흘리기 | 비트시트 1일차 | 혈통 설정은 세계관 문서에서 아직 [제안]. **혈통 확정 뒤에** 쓴다 |
| FOV 애니메이션(나무 접근 시 광각, 5일차 망원, 돌리줌) | 연출 기법 1.2·2.3 | 쓸 수 있으나 멀미 위험. 번역 문서 3장 원칙대로 5일차 한 번만. 나무 접근 광각화는 뺀다(걷는 중 FOV 변화는 멀미가 가장 심함) |
| Irréversible 저주파 주파수 27/28Hz | 연출 기법 4.3 | [미확인]. 어느 쪽이든 일반 스피커·헤드폰으로는 거의 재생이 안 되는 대역이다. 게임에서는 40~60Hz대 드론에 공기 떨림 같은 질감을 섞는 쪽이 현실적 [제안] |

## 3. 장면별 연출 지침 (세 문서 통합)

| 장면 | 이야기의 역할 (작법) | 화면·소리 (연출) | 제어권 (번역) |
|---|---|---|---|
| 기숙사 기상 | 날마다 같은 오프닝 이미지, 작은 차이 | 매일 같은 각도, 천장·창·소리 중 하나만 변화. 형광등 같은 실용 조명 | 3 → 0 |
| 복도·잠긴 문 | 제한 = 보호라는 표면 | 문틀 = 프레임 속 프레임, 정면 대칭. 문 하나가 날마다 달라짐(P.T.) | 0 |
| 로비 NPC | "고맙네. 당신의 헌신." 심기. 설명 4개는 쪼개서 | 가까이 서게 되는 공간. 뜻이 뒤집히는 날엔 몸을 돌리지 않음 | 1~2 |
| 꿈 진입 | 크로스커팅(현실↔꿈) | 긴 암전 + 누운 시선 방향 = 꿈에서 눈 뜨는 방향(매치 컷) | 4 |
| 꿈의 들판·나무 | 결말의 선제 암시 | 롱테이크 걷기, 나무는 1점 투시 랜드마크. 발명된 소리(꿈) vs 실제 소리(현실) | 0 |
| 여자·아이 | 서스펜스: 플레이어만 겹쳐 봄 | 원경 인물(구로사와 기요시), 가만히 앉아 있는 것 자체가 위협 | 0 |
| 빈 의자 | 0일차의 끝, 복선 | 연출 기법 7장 콘티 + 2장 정리(걷기 흔들림 끄기, 숨 멈춤, 드론 분리) | 3 |
| Day 표제 | 인터타이틀 | "Day N" 캡션을 날마다 다른 문구로 | 4 |
| 5일차 진실 | 아나그노리시스 = 페리페테이아, 모든 복선 회수 | 지나온 공간을 다른 상태로 다시 걷기, 플레이어가 마지막 행동을 직접 함. FOV 좁힘·글리치 전환은 딱 한 번 | 0 → 3 |

## 4. 결정이 필요한 것

1. 1~4일차 비트시트(`시나리오_작법.md` 7장)를 기본 틀로 채택할지
2. 여자·아이의 얼굴을 끝까지 숨길지
3. 혈통·고문서 설정 확정 여부(1일차 복선이 여기에 걸림)
4. 착석 연출 개선에 필요한 코드 두 가지(카메라 흔들림 끄기, 드론 분리)를 개발 작업으로 넘길지
