# 비트시트: 몰락형 (계속 하강)

> - 작성 2026-09-17, 지휘실. `비트시트_오이디푸스형.md`와 나란히 비교하려고 짠 두 번째 안
> - 확정 = `0일차_기획.md`·`세계관_리좀솔루션.md`에 있는 것. 나머지는 전부 [제안]
> - 곡선의 뼈대가 되는 1편 대사: "나는 육신을 잃었습니다. 그저 남아있을 뿐이죠."

## 1. 핵심 아이디어: 매일 하나씩 내어 준다

오이디푸스형은 "희망이 올라갔다 떨어지는" 이야기다. 몰락형은 **처음부터 끝까지 잃기만 하는** 이야기다. 반전의 충격 대신 **다음엔 무엇을 잃을까 하는 두려움(dread)**이 끝까지 이어진다. Hereditary나 The Witch처럼 파멸을 향해 천천히 조여 가는 호러에 가깝다.

단조로운 하강을 버티게 하는 장치는 둘이다.

1. **봉헌.** 매일 밤 꿈에서, 현실에서 가져온 것 하나를 나무 아래 두어야 꿈이 끝난다. 다음 날 아침 그것이 현실에서 사라져 있다. 플레이어가 **직접** 내어 준다(Mouthwashing식 공모). 0일차 "고맙네. 당신의 헌신."이 여기서 문자 그대로가 된다
2. **두 곡선의 교차.** 현실은 매일 비워지고, 꿈은 매일 채워진다. 루즈벨트가 가진 것은 계속 줄지만 꿈은 점점 따뜻하고 선명해진다. 5일차에 꿈이 현실보다 "살 만한 곳"이 되어 있고, 그래서 갇힌다

```
 높음 | R                   D
      |    R             D
      |       R       D
      |         R  D          ← 3일차 교차
      |         D  R
      |      D        R
 낮음 | D                   R
      +--+--+--+--+--+--
         0  1  2  3  4  5
   R = 현실에서 루즈벨트가 가진 것 (계속 하강)
   D = 꿈의 선명함·온기 (계속 상승)
```

## 2. 잃는 순서

작은 것에서 큰 것으로, 바깥에서 안으로.

| 날 | 내어 주는 것 | 다음 날 현실에서 사라지는 것 | 1편과의 연결 |
|---|---|---|---|
| 1 | **기억** | 가족사진의 얼굴, 대화 선택지 하나 | 기획: 나무 근처 기억 상실은 흔함 |
| 2 | **이름** | 문 명패, 연구원들이 이름을 부르지 않음 | 1편: 검열된 사건 기록에 "루즈벨트"만 반복됨 |
| 3 | **일** | 자기 연구실이 치워짐 | 1편: 고문서, "세대를 걸쳐 준비해온 결과" |
| 4 | **몸** | 발소리, 거울에 비친 모습, 환경음 | 1편: "육신을 잃었습니다" |
| 5 | **자기 자신** | 전부. 빈 의자에 앉음 | 1편: "이 꿈의 공간에 갇혀버렸습니다" |

## 3. 날짜별 비트

| 날 | 현실 (연구소) | 꿈 (중간계) | 봉헌 |
|---|---|---|---|
| **0** 안식 | 기억 상실, 등급 강등. 그래도 **가장 편안한 날**: "업무는 끝났네, 쉬게." "고맙네. 당신의 헌신." **(확정)** | 회색 하늘, 멀리 나무. 의자 3개. 여자·아이는 흐릿한 실루엣. 빈 의자에 앉음 **(확정)** | 없음. 앉는 동작만 배움 |
| **1** 기억 | 기숙사 책상의 가족사진. 여자·아이가 있지만 루즈벨트는 누군지 모름. 로비 NPC: "사진은 가지고 계셔도 됩니다" | 나무 아래 작은 받침대가 생김. 사진을 두어야 의자가 앉을 수 있게 됨. 여자의 윤곽이 조금 선명해짐 | 사진 → 다음 날 액자 속 얼굴이 비어 있음 |
| **2** 이름 | 기숙사 문 명패, 식당 배식 명단에 이름. 연구원 한 명이 이름을 부르려다 멈춤 | 강가에 배가 매여 있음. 여자와 아이가 배에 타 있음. 아이가 루즈벨트를 부를 듯 입을 엶(소리 없음) | 명패 → 다음 날 문에 이름 없음. 연구원들은 "선생님"이라고만 함 |
| **3** 일 (교차점) | **접근 등급 일부 복구.** 새 구역이 열림(기획 8장 "쟁취"는 유지). 그런데 열린 곳은 자기 옛 연구실이고, 짐이 상자에 담기는 중. 자기 필체의 나무 연구 일지 | 배가 나무 쪽으로 천천히 흘러감. 루즈벨트는 강가를 따라 걸음. 꿈에 처음으로 색(햇빛 한 줄기) | 연구 일지 → 다음 날 연구실이 비어 있음. **얻을수록 잃는다** |
| **4** 몸 | 발소리가 들리지 않음. 거울에 비친 모습이 흐림. 환경음이 절반. 로비 NPC만 여전히 친절함 | 배가 나무 아래에 닿음. 여자와 아이가 의자에 앉아 있음. 꿈 전체가 따뜻하고 선명함. 루즈벨트의 발소리는 **꿈에서** 들림 | 봉헌할 물건이 없음. 받침대 앞에 서면 그림자가 받침대에 남음 |
| **5** 자기 | 거의 무음. 복도에 아무도 없음. 로비 NPC 한 명만 남아 0일차와 **같은 대사**: "고맙네. 당신의 헌신." | 가장 선명하고 따뜻한 꿈. 빈 의자에 앉음(0일차와 같은 동작). 진실을 앎 → 그대로 갇힘 **(확정 뼈대)** | 자기 자신 |

## 4. 5일차: 무엇이 드러나는가

오이디푸스형은 5일차에 "희망이 거짓이었다"가 드러난다. 몰락형은 **"잃은 게 아니라 바친 것이었다"**가 드러난다.

- 매일 밤 받침대에 둔 것은 의식의 제물 목록이었다. 아내와 딸에 이어, 마지막 순교자는 루즈벨트 자신
- 꿈이 따뜻해진 건 루즈벨트가 바친 것으로 중간계가 채워졌기 때문이다
- 0일차 "당신의 헌신"은 처음부터 문자 그대로의 뜻이었다
- 5일차 꿈은 "가족과 함께 있다고 믿게 되는 중간계"의 시작까지만. 깨달음과 자살은 1편 엔딩 몫이다

## 5. 오이디푸스형과 비교

| | 오이디푸스형 | 몰락형 |
|---|---|---|
| 감정 | 희망 → 배신 | 두려움 → 체념 |
| 5일차 충격 | 큼(반전) | 작음. 대신 누적된 무게 |
| 플레이어 동기 | "가족을 구한다" | "다음엔 무엇이 사라지나" + 봉헌을 해야 꿈이 끝남 |
| 기획 8장 코어 루프 | 그대로(꿈에서 얻어 현실에서 씀) | **방향이 반대**(현실에서 가져가 꿈에 바침). 수정 필요 |
| 기획 8장 "제한 구역 쟁취" | 그대로 | 유지하되 "열수록 잃는다"로 뜻이 바뀜 |
| 1편 "지켜볼 수밖에" | 막을 수단이 없어야 함 | 더 잘 맞음. 가족을 구하려는 행동 자체가 없음 |
| 1편 "가족을 구할 수 있을 줄 알았다" | 딱 맞음 | **약함.** 구하려는 희망이 표현되지 않음 |
| 제작 | 1~4일차 꿈마다 새 이벤트 | 날마다 **빼는** 연출(물건·소리·사람 제거)이 많아 더 쌈 |
| 위험 | 정점이 약하면 5일차 추락도 약함 | 단조로움. 플레이어가 무력감에 지침 |

## 6. 몰락형의 위험과 대응

- **단조로움.** 매일 같은 세기로 떨어지면 무뎌진다. 잃는 것의 **종류**를 바꾼다(물건 → 사회적 이름 → 공간 → 감각 → 자기). 4일차는 봉헌할 물건이 없다는 것 자체로 박자를 깬다
- **"왜 계속하나".** 봉헌 없이는 꿈이 끝나지 않아 다음 날로 못 간다(진행의 강제). 더해서 꿈이 나날이 좋아지는 것이 당기는 힘이 된다
- **선택권 없는 봉헌의 피로.** 날마다 후보 두 개 중 하나를 고르게 한다 [제안]. 결말은 같지만 사라지는 디테일이 달라져, 플레이어가 "내가 골랐다"는 무게를 진다. `GameState.items` + 플래그 + `ConditionalObject`로 구현 가능
- **1편 대사와의 틈.** "가족을 구할 수 있을 거라고요"를 살리려면, 2일차 아이가 부를 듯한 장면 뒤에 루즈벨트가 **배를 쫓아가려다 발이 안 움직이는** 짧은 순간을 하나 넣는다. 희망은 한 번만 비치고 곧 꺼진다

## 7. 기존 시스템으로 되는지

| 비트 | 쓰는 것 | 상태 |
|---|---|---|
| 사진·명패·일지 봉헌, 다음 날 사라짐 | `GameState.items` + `ConditionalObject`(requiredItem / forbiddenFlag) | 있음 |
| 받침대에 두어야 의자 활성 | 의자 `CanInteract`에 플래그 조건 추가 | 작은 수정 |
| 날마다 줄어드는 환경음·발소리 | `AmbienceSettings.masterVolume`을 Day별로, 발소리 | 환경음 있음, **Day별 값·발소리는 없음** |
| 꿈의 배 | `Scripts/Water` | 있음 |
| 거울에 흐린 모습 | 셰이더·렌더 텍스처 | **없음** |
| `Dream_01`~`Dream_05` | 씬 | **없음** |
