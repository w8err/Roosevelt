# 0일차 기획

- 작성 2026-09-12. 설정이 부딪히면 `../02_세계관/세계관_리좀솔루션.md`가 우선
- 범위: 0일차(튜토리얼) MVP, 그리고 1~5일차가 이어 쓸 시스템 기반

## 1. 게임 구조
- 0일차(튜토리얼) + 1~5일차. 1편(인수인계 + 5일)과 같은 구조
- 연구소는 '나무'를 연구한다. 나무 = 가미긴(악마의 나무). R.S(Rhizome)라는 이름도 여기서 나온다
- 5일 뒤 나무에 열매가 맺히면 의식과 연구가 끝난다
- 루즈벨트의 아내와 딸은 5일 동안 의식장에 갇혀 있다. 의식장은 실험실이 아닌 별도 장소
- 엔딩은 배드엔딩 1종. 5일차 꿈에서 진실을 알게 되고 그대로 중간계에 갇힌다. 플레이어가 무엇을 해도 의식은 성공한다
- 제작은 선형(하루에 꿈 하나)으로 먼저 하고, 가능하면 나중에 분기를 늘린다

## 2. 0일차 흐름 (= MVP 완료 조건)
기숙사 방에서 깨어남 → 복도(다른 문은 전부 잠김) → 중앙 로비(대부분 접근 불가)에서 NPC와 대화 → 기숙사 침대에서 잠 → 꿈 → 거대한 나무까지 걸어감 → 빈 의자에 앉음 → 연출 → 페이드아웃 → Day 1 저장

0일차에 가르칠 것: 이동, 상호작용, 대화, 수면, 꿈 진입

## 3. 현실: 로비 NPC
지나치게 친절하다. 전하는 내용:
- 너는 '수면' 실험을 받은 뒤 기억에 이상이 생긴 것 같다. 수면은 고등 신경 활동을 억제한 유도 혼수로, 중간계에서 비인간적 존재와 접촉하는 실험이다
- 네 업무는 끝났다. 기억 이상 때문에 접근 등급만 낮춘다. 기숙사·식당은 자유롭게 다녀도 된다. 보안 규정상 시설 밖으로는 못 나간다
- 연구소는 나무를 연구하고, 5일 뒤 열매가 맺히면 연구가 끝난다
- "고맙네. 당신의 헌신." 후반에 뜻이 뒤집힌다

설정 메모 (플레이어에게 설명하지 않음):
- 나무 근처에서는 기억 상실이 흔하다. 연구원들은 익숙해서 시큰둥하다. 그래서 이 NPC의 친절이 더 튄다
- 접근 제한은 기억을 잃은 사람이 사고 치지 않게 막는 조치일 뿐이다. 추방이나 강등이 아니다
- 핵심 연구원들은 루즈벨트의 가족이 제물이 될 것을 안다
- 루즈벨트는 의식을 주장하지 않았다. "필요한 희생"은 찬성파 동료의 논리이고, 루즈벨트가 이 논리를 쓰는 건 1편 시점에 경비원들을 대할 때다

## 4. 꿈 (Dream_00)
- 회색 하늘, 조용한 들판이나 얕은 숲. 야외 숲 에셋을 가져다 쓴다
- 거대한 나무가 멀리서도 보이고 실제로 걸어갈 수 있다. 0일차에는 단순한 형태이고, 날마다 열매가 자란다
- 인간·동물·기계 오염은 거의 보여주지 않는다. 상징만 두고 설명하지 않는다
- 나무 아래 의자 3개. 여자와 아이가 앉아 있고(얼굴·정체는 불명확) 하나는 비었다. 처음부터 배치해 두고, 멀리서 실루엣이 보여도 된다
- 빈 의자에 앉으면: 입력 잠금 → 착석 위치로 이동 → 카메라가 여자·아이·나무를 한 프레임에 담음 → 환경음 감소 → 대기 → 페이드아웃 → Day 1
- 숨은 뜻: 여자·아이·루즈벨트, 의식의 피해자 셋. 두루뭉술하게 표현한다
- 1일차 이후 후보: 여자와 아이가 배를 타고 강 위로 멀어진다(단절의 시작)

## 5. 시스템

| 시스템 | 0일차에 필요한 것 | 현재 코드 |
|---|---|---|
| Player | 1인칭 이동·시점, 입력 잠금 | `FirstPersonController` 있음(달리기·스태미나 유지). 입력 잠금 없음 |
| Interaction | `IInteractable`(Interact/GetPrompt/CanInteract), 화면 중앙 레이캐스트, 프롬프트 UI. 대상: Door·NPC·Bed·Chair | 컨트롤러가 `LabDoor.Toggle()`을 직접 부름. `LabDoor`에 `locked` 있음 |
| State / Flag | 아래 상태 설계 참고 | 없음 |
| Dialogue | ScriptableObject 노드: 화자, 대사, 조건부 선택지, 플래그 설정. 대화 UI는 한글 픽셀 폰트 | 없음 |
| Transition | 입력 잠금 → 페이드아웃 → 씬 로드나 순간이동 → 페이드인 → 잠금 해제. 문 이동, 꿈 진입·종료가 같은 전환을 쓴다 | `RoomPortal`(닿으면 이동하는 트리거)에 페이드+순간이동 있음. 전환 컨트롤러로 옮긴 뒤 삭제 |
| Dream | Bed가 DreamContext(Day·플래그·아이템)를 만들고 꿈 씬 로드. 꿈 이벤트는 Trigger + Condition + Action(예: 나무 구역에서 안개·환경음 변경) | 없음 |
| Sequence | 페이드, 카메라 잠금·LookAt, 대기, 오브젝트 켜기/끄기, 오디오 페이드. Timeline은 연출이 복잡해지면 | 없음 |
| Audio | 현실: 형광등·환풍기·컴퓨터 팬·먼 기계음. 꿈: 저주파 드론·바람·나무 마찰·정체불명의 소리. 멜로디·보컬·비트 없음 | 없음 |
| Save | Day 1에 들어갈 때 Day·플래그 저장 | 없음 |

### 상태 설계
- GameState는 Day(0~5)만 가진다. 지금 현실인지 꿈인지는 로드된 씬으로 안다
- 진행 조건은 전부 플래그로 쓴다. 0일차에는 `TalkedToLobbyNPC`(침대 조건)와 `DreamSatChair` 두 개면 된다
- 대화·연출 중인 상태는 따로 두지 않고 입력 잠금으로 처리한다. 잠금은 요청 수를 세서, 대화 중에 연출이 겹쳐도 먼저 풀리지 않게 한다
- 저장: Day, 플래그. 불러오면 현실 씬의 기숙사에서 시작한다

### 씬
- `Reality` 하나: 기숙사·복도·로비(이후 식당 등). 날짜별 차이는 Day와 플래그로 켜고 끈다
- 방 이동: 방들은 한 씬 안에 서로 떨어진 공간으로 둔다. 문과 상호작용하면 화면이 어두워지고, 다음 방 입구로 순간이동한 뒤 밝아진다. 문은 열리지 않는다. 잠긴 문은 "잠겨 있다" 프롬프트만 띄운다
- `Dream_00`~`Dream_05`: 꿈만 날짜별로 따로 둔다

## 6. 지금 만들지 않음

## 7. 구현 계획
회색 박스로 0일차를 처음부터 끝까지 먼저 돌리고(1~6단계), 아트·소리는 그 뒤에 교체한다(7단계). 거대한 나무·의자 같은 모델은 코드 작업과 병행해 Blender로 만든다.

| 단계 | 내용 | 완료 기준 |
|---|---|---|
| 1. 상호작용 | 입력 잠금(요청 수를 셈), `IInteractable` + `PlayerInteraction`(컨트롤러에서 분리), 화면 중앙 프롬프트 | `Lab_Playground`에서 문을 조준하면 프롬프트가 뜨고, 잠긴 문은 "잠겨 있다" |
| 2. 전환·뼈대 | 페이드 + 순간이동 전환, 이동용 문, GameFlow(자동 생성, 씬이 바뀌어도 유지): Day·플래그·JSON 저장 | 문을 누르면 암전 → 다음 방 → 밝아짐. 어느 씬에서 Play해도 동작 |
| 3. 현실 공간 | `Reality.json`(기숙사 방·복도·로비)을 `LabSceneBuilder`로 씬 생성. 빌더에 이동용 문(목적지 지정)을 추가. 가구는 임시 박스 | 기숙사 → 복도 → 로비를 문으로 이동. 복도의 다른 문은 잠김 |
| 4. 대화 | `DialogueData`, 대화 UI(한글 픽셀 폰트), 로비 NPC → `TalkedToLobbyNPC`, 침대 조건 | 대화한 뒤에만 잠들 수 있음 |
| 5. 꿈 | `Dream_00.json`(숲 에셋, 회색 하늘, 안개), 임시 거대 나무(기존 나무 확대), 여자·아이·의자 임시 배치 | 침대 → 꿈 → 나무까지 걸어감 |
| 6. 의자 연출 | 착석 연출 → 페이드 → Day 1 저장 → MVP는 "Day 1" 화면으로 끝 | 2장 흐름을 한 번에 끝까지 플레이 |
| 7. 아트·소리 | 거대 나무, 의자, 침대, 여자·아이 모델, 현실·꿈 환경음 | 회색 박스가 전부 교체됨 |

## 8. 장기 코어 루프
현실에서 행동 → 플래그/DreamContext에 기록 → 수면 → 조건에 따라 꿈이 바뀜 → 꿈에서 아이템 획득 → 현실에서 실험 → 새 플래그 → 다음 꿈 변화

콘텐츠는 "무엇을 봤나·만졌나·가졌나·어떤 꿈을 꿨나"로 갈린다. 제한 구역은 플레이어가 쟁취할 영역이다. 그래도 의식은 성공한다.

## 9. 미정
- 업무가 끝났는데도 매일 밤 중간계에 가는 이유
  - [제안] 실험 후유증. 수면 실험으로 한 번 이어진 뒤로는 나무 가까이서 자기만 해도 중간계로 끌려간다. 연구원들은 흔한 일이라 내버려 둔다
- 제한 구역을 여는 방법(1~5일차 진행 축)
- 의식장 위치, 5일차 꿈 내용
