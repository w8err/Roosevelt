# 비주얼 콘셉트: 리좀 오염

작성 2026-09-12. Roosevelt의 아트 디렉션과 환경·적·오브젝트 제작 기준이다. 서사상 확정 설정은 `../02_세계관/세계관_리좀솔루션.md`가 우선하며, 이 문서는 그 설정을 화면과 플레이 공간에서 어떻게 보이게 할지 정의한다.

## 1. 한 줄 정의

**Rhizome은 인간·동물·기계를 각기 다른 방식으로 접목하여, 연구시설과 숲 전체를 하나의 감시하고 자라나는 뿌리 네트워크로 재편한다.**

이 프로젝트의 공포는 ‘나무 괴물’ 하나가 아니라, 모든 개체와 환경이 같은 근원을 공유하며 이미 연결돼 있다는 깨달음에서 나온다.

## 2. 핵심 비주얼 원칙

| 키워드 | 화면에서의 해석 |
|---|---|
| 뿌리 | 땅, 벽, 기계, 신체를 관통하고 서로 잇는 선. 케이블·배관도 뿌리처럼 보일 수 있다 |
| 군집 | 같은 얼굴·눈·가지·렌즈가 반복되어 하나의 집단의식을 암시한다 |
| 감시 | 수피 속 눈, CCTV 렌즈, 관찰창, 화면이 플레이어를 향한다 |
| 침식 | 시설의 구조가 숲에 의해 덮이는 것이 아니라, 처음부터 한 몸으로 자란 듯 접합된다 |
| 정착 | 개체는 걷거나 뛰기보다 땅·벽·천장에 박혀 자라난 것처럼 보인다 |
| 목질화 | 피부가 나무 껍질로 바뀌는 장식이 아니라, 인간의 구조 자체가 줄기·뿌리로 재편된 결과로 보인다 |
| 의례성 | 기둥, 제단, 줄 세운 관찰체, 대칭 배치로 숭배·봉헌·재배의 인상을 만든다 |

### 2.1 공포의 태도
- 공격 자세보다 **가만히 서 있는 것 자체**가 위협이어야 한다.
- 개체의 존재보다 개체가 놓인 자리, 주변의 반복 패턴, 연결된 설비가 먼저 불길함을 만든다.
- 인간·나무·기계의 경계를 분명히 구분하지 않는다. 무엇이 생물이고 무엇이 환경인지 한눈에 확정되지 않게 한다.
- 움직이는 적도 ‘달리는 동물’보다, 뿌리가 당겨 옮기거나 자라난 덩어리가 위치를 바꾸는 인상을 우선한다.

### 2.2 피해야 할 방향
- 판타지 나무정령, 귀여운 숲 요정, 화려한 다크 판타지 식물.
- 인간이 나무 갑옷을 입거나 덩굴을 장식처럼 두른 수준의 단순 결합.
- 슬렌더형 인간 괴물의 반복, 일반적인 식물 좀비, 피·근육 중심의 공격적 고어.
- 개체마다 색·형태가 전부 달라 같은 네트워크라는 인상이 사라지는 구성.

## 3. 오염의 세 계통

세 계통은 서로 다른 종족이 아니다. 하나의 Rhizome 네트워크가 매개체에 따라 드러나는 서로 다른 표현이다.

| 계통 | 오염이 드러나는 방식 | 서사적 역할 | 주 사용 장소 |
|---|---|---|---|
| 인간계 | 하체의 뿌리화, 줄기 속 얼굴, 과장된 눈·입·목, 여러 얼굴의 군집 | 숭배·희생·접목 | 관찰실, 의례 공간, 복도, 실험실 |
| 동물계 | 눈·턱·다리·뿔·꼬리의 과증식, 거대화, 여러 동물 특징의 오류 같은 혼합 | 제물·사육·자연 침식 | 숲, 외곽 시설, 추적 구간 |
| 기계계 | CCTV 군집, 렌즈의 눈화, 케이블의 뿌리화, 서버랙과 줄기의 융합 | 기록·감시·전파 | 보안실, 서버실, 연구소 외벽 |

### 3.1 공통 반복 문법
- **눈/렌즈:** 생체 눈과 CCTV 렌즈는 동일한 크기·배치·빛의 언어를 공유한다.
- **얼굴:** 수피의 무늬, 모니터 노이즈, 표본의 배열에서 얼굴처럼 읽히는 반복을 만든다.
- **뿌리/케이블:** 유기물과 전선은 같은 접합점에서 자라나며 어디까지가 어느 재질인지 분명히 나누지 않는다.
- **수직 토템:** 인간형 나무, 서버랙, CCTV 기둥, 관찰실 표본은 세로로 길고 의례적인 실루엣을 공유한다.

## 4. 개체·적 계통

게임플레이 역할은 구현 단계에서 확정한다. 아래는 실루엣, 공간 역할, 공포 연출을 위한 1차 계통이다.

| 계통 | 역할 | 실루엣과 연출 |
|---|---|---|
| `Seeded` | 인간계 초기 오염체 | 인간형의 비율이 남아 있지만 피부·다리·목 일부가 목질화. 다른 계통의 수를 암시하는 배경/근거리 위협 |
| `Rooted` | 공간 장악형 | 하체가 바닥에 뿌리내린 인간형. 팔·가지로 통로를 막거나 고개·시선만 바꾼다 |
| `Choir` | 감시·정신간섭형 | 여러 얼굴과 상반신이 한 줄기/기둥에 융합. 발성, 환청, 시선으로 공간을 점유 |
| `Arborform` | 중대형 정예 | 줄기·인체·토템의 중간. ‘개체’보다 방 한가운데 자란 구조물처럼 보인다 |
| `Witness Tree` | 환경 감시형 | 수피 속 눈과 얼굴이 열린 나무. 이동보다 응시·조명 변화·기계 연동으로 존재를 드러낸다 |
| `Core Bloom` | 네트워크 중심 | 시설의 구조, 뿌리, 서버, 표본과 연결된 중심체. 단일 생물 보스보다 공간 자체의 기관처럼 연출 |

## 6. 형태·색·렌더링

### 6.1 형태
- 세로로 긴 목, 줄기, 기둥, CCTV 지지대를 반복한다. 하체는 다리보다 뿌리·전선·배관으로 지면에 정착한다.
- 얼굴은 최소화하거나 수피·화면·군집 속에 반복한다. 명확한 표정 연기보다, 눈과 입의 위치가 어긋난 듯한 정적 인상을 우선한다.
- 중요한 실루엣은 320×240 목표 렌더와 3m·8m 거리에서 구분되어야 한다.
- 특수 개체는 화면에 한 번에 많이 두지 않는다. `Rooted`·`Witness Tree`처럼 먼저 발견되는 실루엣 하나를 남겨 둔다.

### 6.2 색과 조명
- 기본 분위기는 저채도의 회녹색, 탁한 베이지, 깊은 청록/검정, 옅은 안개다.
- 기존 실내 팔레트의 청록·베이지는 구조물과 주변광에 사용하고, 빨간 경고색은 출입 통제·감시·위험의 국소 표식으로만 쓴다.
- 강한 단색 조명은 길 유도, 감시 대상, 의례 공간의 중심에만 둔다. 화면 전체에 색광을 균일하게 뿌리지 않는다.
- PS1식 저해상도, Point 텍스처, 정점 흔들림, 텍스처 왜곡은 `그래픽_레퍼런스.md`의 원칙을 따른다. 실제 에셋의 실루엣과 조명 명암이 먼저 읽혀야 한다.

## 7. 환경 제작 규칙

- 숲은 일반 나무를 빽빽이 심는 배경이 아니라, 뿌리 네트워크가 만든 경계이자 감시 장치다. 가까운 나무·뿌리·바위는 수동 배치하고, 중거리 식생은 반복, 원경은 안개·실루엣으로 대체한다.
- 건물 벽을 뿌리가 덮는 데서 그치지 않는다. 배관과 케이블이 뿌리의 갈래처럼 시설 안팎을 관통하고, CCTV 기둥과 나무줄기가 닮은 구조를 이룬다.
- 공간마다 인간계·동물계·기계계 중 하나를 주 문법으로 정하고, 다른 계통은 흔적 또는 보조 연출로 쓴다. 모든 요소를 한 방에 섞어 정체성이 흐려지는 것을 피한다.
- 진행 경로는 가로등, 경고등, 표지판, 밝은 수피, 건물 실루엣 중 적어도 하나로 읽힌다. 공포 연출이 길찾기를 망치지 않게 한다.
- 보이지 않는 충돌벽 대신 나무, 펜스, 급경사, 물, 시설물처럼 물리적 이유가 보이는 경계를 둔다.

## 9. 현재 제작 우선순위

1. **환경 공통 문법:** 뿌리/케이블, 눈/렌즈, 안개, 경고등, 시설 외벽의 결합 규칙을 먼저 테스트한다.
2. **연구소 프로토타입:** Root Corridor 또는 Server Grove 한 구역에서 인간계와 기계계 오염을 함께 검증한다.
3. **야외 숲 프로토타입:** `../04_에셋_제작/에셋_규격서_야외숲.md`의 Forest Test에 죽은 나무, 기형 나무, 펜스, CCTV, 원경 안개를 배치한다.
4. **상호작용 오브젝트:** Root Terminal 하나를 제작해 ‘시설 제어’와 ‘뿌리 네트워크’가 한 화면에서 연결되는지 검증한다.
5. **특수 개체:** 이동/전투 구현 전에는 `Rooted` 또는 `Witness Tree` 하나를 정적 배치하여 1인칭 실루엣과 조명부터 검증한다.
