## Pixel Crushers Dialogue System 실사용 저장소

Pixel Crushers **Dialogue System for Unity**는 에셋스토어 유료 제품이다. 아래 저장소들은
에셋 자체를 포함하지 않고 **API만 호출**하므로 사용 패턴을 보기에 안전하다.

### CaosCreations/SpaceTruckin — MIT 계열, 17개 파일 ⭐가장 실전적

실제 상용 규모 게임. `Assets/Scripts/Dialogue/` + `Singletons/DialogueSingletons/`

- `DialogueUtils.cs` — `DialogueLua.DoesVariableExist`, `DoesTableElementExist`,
  `GetActorField` 등 **Lua 변수/액터 테이블 접근 래퍼**. Dialogue System이 내부적으로
  Lua 환경을 쓰기 때문에 게임 상태와 연결하려면 이 계층이 반드시 필요하다.
- `DialogueDatabaseManager.cs` — 대화 DB를 코드에서 조회. ID로 대화 시작하는 헬퍼를
  직접 만들어 씀("Because PixelCrushers didn't include this...").
- `DialogueEventManager.cs`, `DialogueZoneLockManager.cs` — 대화 중 구역 잠금.
  **Roosevelt의 `InputLock`과 같은 역할**이라 비교해볼 것.
- `DialogueLineSkip.cs` — 대사 스킵 입력 처리
- `FacialExpressionSubtitlePanel.cs` — 자막 패널을 확장해 표정 연동
- `NPCActor.cs` — NPC ↔ 대화 액터 바인딩

### centre-for-educational-technology/Melange — 라이선스 없음 ⚠️, 21개 파일

읽기만. 복사 금지. 대신 **Lua 연동 예제가 제일 풍부**하다.

- `MyLuaFunctions.cs` — **커스텀 Lua 함수 등록**. Roosevelt가 `Roosevelt.Core`의
  플래그·GameState를 대화 조건문에 노출하려면 정확히 이 패턴이 필요하다.
- `ChangeLuaVariableOnClick.cs`, `ResetLuaVariables.cs` — Lua 변수 읽기/쓰기
- `SequencerCommandStartConversation.cs` — **커스텀 시퀀서 명령 추가**.
  Dialogue System의 Sequencer는 대사마다 연출(카메라·오디오·애니메이션)을 붙이는 기능인데,
  Roosevelt의 `ScreenTransition` 같은 걸 여기에 명령으로 등록할 수 있다.
- `LoadLevelOnConversationLua.cs` — 대화 결과로 씬 전환
- `StartConversation.cs`, `StartConversationOnClick.cs` — 대화 시작 트리거

### AleFeng/unity-visual-novel-framework-dialogue-system — MIT, 8개 파일

Dialogue System 위에 얹는 VN 프레임워크. UPM 패키지 구조라 **래핑 설계**를 보기 좋다.
에셋 본체는 없고 `Docs~/Setup/PixelCrushers/`에 `.asmdef` 스텁만 들어있다.

- `VnConditionBridge.cs` + `Editor/VnConditionLuaFunctionInfoGenerator.cs`
  — 조건식을 Lua 함수로 브리지하고, 에디터에서 자동완성 정보를 생성
- `VnStoryManager.cs`, `VnStoryPlayer.cs`, `VnPlaybackController.cs` — 재생 제어
- `VnReadHistory.cs` — 읽은 대사 기록 (백로그)
- `VnResponseButton.cs` — 선택지 버튼

## Roosevelt 적용 시 봐야 할 순서

1. `SpaceTruckin/DialogueZoneLockManager.cs` — 대화 중 입력 잠금을 어떻게 걸고 푸는지
2. `Melange/MyLuaFunctions.cs` — 게임 플래그를 대화 조건으로 노출하는 방법
3. `Melange/SequencerCommandStartConversation.cs` — 연출 명령 확장
4. `SpaceTruckin/DialogueUtils.cs` — Lua 상태 접근 래퍼 계층 설계

## 받지 않은 것

`IAMColumbia/Dialogue-System-Third-Person-Starter-Kit`과 `Dialogue-System-2D-Starter-Kit`은
Pixel Crushers 에셋 **전체(약 1,100개 파일)를 라이선스 표기 없이** 공개 저장소에 올려둔 것이다.
"educational license"라고 적혀 있지만 공개 재배포는 그 범위 밖이다. 받지 않았다.
